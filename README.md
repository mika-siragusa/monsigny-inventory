# 🍽️ Monsigny Inventory App

App d'inventaire pour le restaurant Monsigny.

## Accès

Ouvre `index.html` dans ton navigateur pour utiliser l'app.

## Caractéristiques

- ✅ Inventaire complet (305+ produits)
- ✅ Données locales (localStorage)
- ✅ Mode offline avec Service Worker
- ✅ Installation mobile (iOS/Android)
- ✅ Restaurant et Rooftop séparés

## Données

- 46 produits Cash Fruits
- 48 produits Sysco
- 211 produits autres fournisseurs
